# Brothers Technology Group (BTG)
## BTG Azure Cloud Transformation
### Executive Summary
Brothers Technology Group (BTG) is a fictional technology company headquartered in Boston, Massachusetts. The company is beginning a strategic migration from an on-premises infrastructure to Microsoft Azure and Microsoft Entra ID.
The objective of this project is to design, build, secure, document, and automate an enterprise Azure environment using Microsoft best practices.
This repository documents that journey from the perspective of BTG's Cloud Engineering team.
