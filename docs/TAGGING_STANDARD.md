# BTG Resource Tagging Standard
## Purpose
This document defines the standard Azure resource tags used throughout the Brothers Technology Group Azure environment.
Applying consistent tags improves governance, cost reporting, operational management, and resource organization.
---
## Standard Tags
| Tag | Example Value | Description |
|------|---------------|-------------|
| Environment | DEV | Deployment environment |
| Project | BTG-Azure-Transformation | Associated business project |
| Department | IT | Business owner |
| Owner | Cloud Engineering | Responsible engineering team |
| ManagedBy | Azure Administrator | Operational owner |
---
## Standard
All Azure resources deployed during the BTG Enterprise Cloud Simulation must include the standard resource tags unless a documented exception has been approved.
